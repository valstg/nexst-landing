# NEXST Landing
Landing comercial en Next.js lista para Vercel.

## Ejecutar
```bash
npm install
npm run dev
```

## Publicar en Vercel
1. Subí esta carpeta a un repositorio de GitHub.
2. En Vercel elegí **Add New > Project**, importá el repositorio y presioná Deploy.
3. Configurá la variable `NEXT_PUBLIC_WHATSAPP_URL` con el enlace completo `https://wa.me/549...` de tu número comercial y volvé a desplegar.

## Antes de publicar
- Reemplazar el logotipo tipográfico provisional por el SVG oficial de NEXST (especialmente la N con flechas).
- Configurar WhatsApp comercial y dominio propio.
- Reemplazar la ilustración del dashboard por capturas reales cuando estén disponibles.
- Validar las funcionalidades comerciales descritas según el producto disponible.
